<GuideSection id="included" title="What you get">
  The starter is a plain shadcn Next.js app: nothing here is a runtime dependency you upgrade around.

  <GuidePoints>
    <GuidePoint>Every component, block, and primitive copied into `components/control-ui` as source you own.</GuidePoint>
    <GuidePoint>The Refined skin wired through `theme.css`, `skin-theme.css`, and `skin.css` — swap packs later with a single install.</GuidePoint>
    <GuidePoint>A `components.json` the registry keeps writing to, so installing or updating an item stays one command.</GuidePoint>
  </GuidePoints>
</GuideSection>
