  color picker, tree view, phone input, timeline, stepper, code diff, or file explorer. Control UI ships the items below

  `components/ui/*`:

<GuideSection id="pickers-inputs" title="Pickers and inputs">
  - [Color picker](/components/color-picker): color formats, presets, contrast helpers, and a gradient editor with draggable stops.
  - [Emoji picker](/components/emoji-picker): searchable, virtualized emoji grid with an emoji-or-icon tabbed variant.
  - [Icon picker](/components/icon-picker): searchable icon grid and color swatches over an icon catalog your app supplies.
  - [Phone input](/components/phone-input): country search, E.164 values, and Zod validation helpers.
  - [Number field](/components/number-field): numeric input with stepper buttons and optional drag-to-change.
  - [Autocomplete](/components/autocomplete): free-text input with search-as-you-type suggestions, unlike a combobox that forces a pick.
  - [Checkbox group](/components/checkbox-group): multi-select checkbox set with shared state and select-all.
  - [Dropzone](/components/dropzone): file intake with validation, managed selection, and drag-activated overlays.
  - [Trigger menu](/components/trigger-menu): caret-anchored `/` command or `@` mention menu for text editors.
  - [Filter bar](/kits/filter-bar): editable field, operator, and value filters with a button or inline search.
</GuideSection>

<GuideSection id="structure-navigation" title="Structure and navigation">
  - [Tree](/components/tree): accessible tree view with roving keyboard navigation, single or multi selection, and animated disclosure.
  - [Timeline](/components/timeline): chronological events with per-event status, connectors, and metadata.
  - [Stepper](/components/stepper): static and interactive workflow steps, horizontal or vertical.
  - [Table of contents](/components/table-of-contents): sticky in-page navigation with scroll-spy range highlighting.
  - [Page layout](/components/page-layout): page shell that owns the scroll container, the measure, and the title and actions row.
  - [Toolbar](/components/toolbar): roving-focus toolbar for editor controls and compact actions.
  - [Dockable panel](/components/dockable-panel): non-modal panel that moves between two edge slots, with a drawer fallback on mobile.
  - [Morphing panel](/components/morphing-panel): compact control that expands into settings, navigation, or an inline confirmation.
</GuideSection>

<GuideSection id="content-code" title="Content and code">

  - [Markdown](/components/markdown): GFM rendering whose code fences compose Code and diff fences compose Code diff.

<GuideSection id="ai-agent" title="AI and agent surfaces">
  shadcn/ui now covers the basic chat parts: message, bubble, attachment, message-scroller, questionnaire, and marker.
  Control UI's own versions of those are left off this list. What it adds is the agent layer around a conversation:

  - [Chat composer](/kits/chat-composer): controlled text, Enter or ⌘ Enter submit, and trigger-menu mentions.
  - [Chat layout](/kits/chat-layout): scrolling conversation with a pinned header and a floating composer dock.
  - [Chat](/templates/chat): chat shell that composes rendered turns and a composer your provider owns.
  - [Activity](/kits/activity): collapsible agent activity with bounded, scrollable detail.
  - [Task list](/kits/task-list): floating task progress pill that expands into the full list.
  - [Context](/kits/context): context-window usage with a derived token graph and a detail inspector.
  - [Inline citation](/kits/inline-citation): multi-source citation with a keyboard-accessible preview.
  - [Source badge](/kits/source-badge): linked source with favicon, hostname, and a fallback.
  - [Markdown block](/kits/markdown-block): assistant markdown output with a header and a copy-source action.
  - [Action bar](/kits/action-bar): hover actions for messages and responses.
  - [Transcript divider](/kits/transcript-divider): run boundaries for steering, interruptions, and condensed context.
  - [Thread rail](/kits/thread-rail): conversation minimap for jumping between turns.

  None of them call a model. They take plain props and callbacks, so the [runtime boundary](/architecture) stays in your app.
</GuideSection>

<GuideSection id="not-listed" title="Left off this list">
  Some Control UI items match a shadcn/ui component under another name, so they are not "missing":

  - Chat message, composer attachment, inline attachment, and user ask: shadcn/ui has message, bubble, attachment, and questionnaire.
  - Form: shadcn/ui documents forms on top of its field component.
  - Responsive dialog: shadcn/ui documents the same dialog-on-desktop, drawer-on-mobile pattern.
  - App shell: shadcn/ui's sidebar ships its own inset layout.
  - Theme toggle: shadcn/ui documents a mode toggle in its dark mode guide.

  For how the two libraries compare beyond coverage, read [Control UI vs shadcn/ui](/control-ui-vs-shadcn-ui).
</GuideSection>
